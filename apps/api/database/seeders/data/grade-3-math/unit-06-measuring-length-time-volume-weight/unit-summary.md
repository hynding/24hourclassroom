# Unit 6 · Measuring Length, Time, Liquid Volume, and Weight · Unit summary

**Weeks:** 21 to 24 · **Standards:** 3.MD.B.4, 3.MD.A.2, 3.MD.A.1, 3.OA.D.8
**Built from:** IM K–5 Math Grade 3, Unit 6, in our own words

## The big ideas

1. **A ruler is a number line for length.** Each inch is split into 2 halves and 4 quarters. Line up one end of an object with 0 and read the mark at the other end. If it does not start at 0, count the spaces from start to end.
2. **A line plot shows many measurements at once.** One X goes above the number line for each thing measured. Count X's to answer "how many", find the tallest stack for "most often", and count only the X's to one side for "longer than" or "shorter than".
3. **Mass is how heavy something is.** A gram is about a paper clip. A kilogram is about a full 1-liter water bottle. Light things use grams; heavy things use kilograms.
4. **Liquid volume is how much liquid there is.** A liter is about a large water bottle. Read the marks on a container the way you read a scale: first find what each mark is worth.
5. **Clocks show time to the minute.** Count the minute hand by 5s and then 1s. The hour hand moves slowly between numbers all hour, so the hour is the number it has passed.
6. **Elapsed time is found with jumps.** Jump to the next o'clock, then on to the end. An hour has 60 minutes, so never subtract times like regular numbers.
7. **Word problems use all four operations.** Picture the story, draw a tape diagram or number line, write an equation with a letter for the unknown, and check with an estimate.

## Strategies with an example each

| Strategy | When to use it | Example |
|---|---|---|
| Read the ruler from 0 | Measuring length | A crayon from 0 to the first short mark after 2 is 2 1/4 inches. |
| Count spaces from the start | The object does not start at 0 | From 3 to 6 1/2 is 3 1/2 inches. |
| Count X's on a line plot | How many, most often, longer than | 1 X, 4 X's and 2 X's make 7 things measured. |
| Compare with a known object | Estimating mass or volume | A melon feels like 2 water bottles: about 2 kg. |
| Find what each mark is worth | Reading a scale or container | Labels 0, 2, 4 with a mark between: the mark between 4 and 6 is 5. |
| Count by 5s, then 1s | Reading the minute hand | 3 small marks past the 7 is 35, 36, 37, 38: 38 minutes. |
| Jump to the o'clock | Elapsed time across the hour | 10:50 to 11:25 is 10 + 25 = 35 minutes. |
| Tape diagram | Equal parts of a total | 18 L shared into 3 jugs: 18 ÷ 3 = 6 L each. |
| Two steps with a letter | Two-step stories | 25 kg − (4 × 5 kg) = k, so k = 5 kg. |
| Round to estimate | Is the answer reasonable? | 39 + 22 is about 40 + 20 = 60, so 61 makes sense. |

## Words to know

| Word | What it means |
|---|---|
| Half inch, quarter inch | One of 2, or one of 4, equal parts of an inch. |
| Line plot | A number line with an X for each thing measured. |
| Mass | How heavy something is, measured in grams (g) and kilograms (kg). |
| Liquid volume | How much liquid, measured in liters (L). |
| Elapsed time | How much time passes from start to end. |
| a.m., p.m. | Midnight to noon, and noon to midnight. |
| Estimate | A close, easy number used to check an answer. |

## Watch out for

- **Starting at the edge of the ruler** instead of at the 0 mark.
- **Reading only the end number** when an object does not start at 0.
- **Counting X's on the line** when the question says "longer than": the X's right on that length do not count.
- **Reading only the labeled numbers** on a scale or container. Count the marks first.
- **Mixing up grams and kilograms.** A rabbit is about 2 kilograms, not 2 grams.
- **Reading the hour hand's nearest number.** At 4:55 the hour hand is almost at 5, but the hour is still 4.
- **Subtracting times like regular numbers.** 3:10 − 2:50 is not 60 minutes; with jumps it is 10 + 10 = 20 minutes.
- **Stopping after one step** in a two-step problem. Read the question again.

## Practice set

1. A pencil starts at 0 and ends at the middle mark between 5 and 6. How long is it?
2. A line plot has 3 X's above 2, 4 X's above 2 1/4 and 2 X's above 2 1/2. How many are longer than 2 inches?
3. Which unit fits the water in a kitchen sink: grams, kilograms or liters?
4. A container's labels are 0, 5, 10 and there are 4 marks between each pair of labels. What is each mark worth?
5. The minute hand is 4 small marks past the 2. How many minutes after the hour is it?
6. Lunch is from 11:45 to 12:20. How long is lunch?
7. A tank has 40 L. 5 buckets of 6 L are poured out. How much is left?

*Answers:* (1) 5 1/2 inches. (2) 4 + 2 = 6. (3) Liters, because it is a liquid. (4) 1, because there are 5 equal spaces from 0 to 5. (5) 10 + 4 = 14 minutes. (6) 15 + 20 = 35 minutes. (7) 5 × 6 = 30 L poured out, and 40 − 30 = 10 L left.
