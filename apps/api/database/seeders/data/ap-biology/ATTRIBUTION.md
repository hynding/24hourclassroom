# Attribution

Every study guide, unit summary, flashcard deck and test item in this
directory was adapted from the two OpenStax biology textbooks below, both
published by Rice University under the Creative Commons Attribution 4.0
International License (CC BY 4.0, https://creativecommons.org/licenses/by/4.0/).
Material was paraphrased, condensed, reorganised around the College Board
AP Biology Course and Exam Description (effective Fall 2025), and extended
with original worked examples and questions. Nothing is reproduced at length.

Items the authors could not source from OpenStax carry
`source: "general knowledge"` in their YAML so a reviewer can find them.

- OpenStax, *Biology for AP® Courses* (2018). https://openstax.org/details/books/biology-ap-courses
