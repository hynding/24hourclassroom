## The ideas that generate every question

1. **An equation is a constraint in symbols.** Define each quantity with its unit, write every contribution, set the expression equal to the total. Patterns: part + part = total; fixed + rate × amount; rate × time.
2. **A solution makes the statement true.** One variable: a number. Two variables: a pair, and the graph is the set of all pairs. Check by substituting.
3. **Equivalent equations share solutions.** Add or subtract the same thing on both sides; multiply or divide both sides by the same non-zero number; rewrite a side as an equal expression. Anything else is suspect.
4. **Two forms of a line, two jobs.** y = mx + b shows rate and starting value; ax + by = c shows two quantities combining into a total, with intercepts c/a and c/b and slope −a/b.
5. **A system asks for the pair that satisfies both.** Graphs cross once (one solution), are parallel (none) or coincide (infinitely many). Substitution and elimination give exact answers.
6. **Inequalities have regions, not points, as solutions.** On a number line: boundary plus a direction, open or closed circle. In the plane: a half-plane with a solid or dashed boundary, decided by a test point. A system of inequalities is the overlap.
7. **Dividing by a negative flips the symbol.** Nothing else does.

## Key formulas and procedures

| Task | Procedure |
|---|---|
| Slope from two points | m = (y₂ − y₁)/(x₂ − x₁) |
| Line from slope and a point | substitute into y = mx + b to find b |
| Intercepts of ax + by = c | x = c/a (set y = 0); y = c/b (set x = 0) |
| Slope of ax + by = c | −a/b |
| Solve for a variable | undo operations on both sides until it stands alone; divide the whole other side |
| Substitution | isolate, substitute in parentheses, solve, back-substitute, check both |
| Elimination | scale one or both equations so a pair of coefficients are opposites, add, solve, back-substitute, check both |
| Classify a system | different slopes: one; same slope, different intercepts: none; same line: infinitely many |
| Solve an inequality | as an equation, reversing the symbol only when multiplying or dividing by a negative |
| Graph ax + by ≤ c | boundary from intercepts, solid (≤, ≥) or dashed (<, >), test (0, 0) unless on the line, shade |
| Model with inequalities | variables, every constraint (plus x ≥ 0, y ≥ 0), region, vertices by solving pairs of boundary equations, interpret |

## Worked examples

**Equation from a table.** x = 2, 5, 8 and y = 11, 20, 29: y rises 9 per 3 units of x, so 3 per unit; at x = 2, y = 11, so at x = 0, y = 5. y = 3x + 5.

**Both forms.** 6x + 4y = 24: intercepts (4, 0) and (0, 6); slope −6/4 = −3/2; y = −(3/2)x + 6.

**Elimination.** 3x + 2y = 19 and 5x − 4y = 17. Double the first: 6x + 4y = 38. Add: 11x = 55, x = 5; then 15 + 2y = 19, y = 2. Check: 25 − 8 = 17 ✓.

**Classify.** 4x − 6y = 10 and −6x + 9y = −15: the second is the first times −3/2; the same line, infinitely many solutions.

**Inequality.** 5 − 3x ≤ 20: −3x ≤ 15, x ≥ −5 (flipped). Test x = 0: 5 ≤ 20 ✓.

**Two-variable constraint.** $90 for pens at $2 and notebooks at $5: 2p + 5n ≤ 90, intercepts (45, 0) and (0, 18), solid, shade toward the origin; (20, 10) costs 90, on the line.

**System of inequalities.** x + y ≤ 10, y ≥ 2, x ≥ 3: a triangle with vertices (3, 2), (8, 2), (3, 7). To maximise 4x + 5y, check the corners: 22, 42, 47. Best: (3, 7).

## Common errors

- Swapping the fixed amount and the rate (11 + 40p for a $40 fee and $11 per pizza).
- Translating "5 less than x" as 5 − x.
- Calling a single number the solution of a two-variable equation or system.
- Reading the slope of ax + by = c as a or a/b instead of −a/b.
- Dividing only part of a side: from 3y = −4x + 24 writing y = −4x + 8.
- Dropping the parentheses when substituting: 3x + 2·2x − 1.
- Scaling one side of an equation before eliminating.
- Saying 0 = 0 means no solution (it means infinitely many).
- Writing < for "at most" or ≥ for "more than".
- Forgetting to flip the symbol when dividing by a negative, or flipping it when subtracting a negative.
- Solid line for a strict inequality; shading without a test point; testing (0, 0) on a line through the origin.
- Leaving out non-negativity in a model; reading vertices from a sketch instead of solving.

## Quick drills (answers at the end)

1. A phone plan is $18 plus $0.04 per minute; write the cost C of m minutes.
2. Is (3, −1) a solution of 2x − 5y = 11?
3. Solve 4x + 7y = 28 for y, and give the slope.
4. Solve: 2x + y = 9 and 3x − 2y = 10.
5. Classify: y = −x + 4 and 2x + 2y = 12.
6. Solve 9 − 2x > 15.
7. Is (2, 1) a solution of y < x and x + y ≥ 3?

*Answers:* (1) C = 18 + 0.04m. (2) 6 + 5 = 11, yes. (3) y = (28 − 4x)/7 = 4 − (4/7)x; slope −4/7. (4) Double the first: 4x + 2y = 18; add: 7x = 28, x = 4, y = 1. (5) Second is x + y = 6, slope −1 both, intercepts 4 and 6: none. (6) −2x > 6, x < −3. (7) 1 < 2 ✓, 3 ≥ 3 ✓: yes.
