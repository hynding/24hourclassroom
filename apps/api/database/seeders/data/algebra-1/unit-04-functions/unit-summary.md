## The ideas that generate every question

1. **A function gives each input exactly one output.** Two inputs may share an output; one input may not have two. Vertical line test on a graph.
2. **f(a) = b is a sentence.** Input a, output b, point (a, b). f(10) asks for an output (evaluate); f(x) = 10 asks for the inputs (solve, possibly several answers).
3. **Rules come from the story.** Fixed amount plus rate times input; starting value minus rate times input; or read the rate and the value at 0 from a table.
4. **Graphs have features with meanings.** Vertical intercept f(0) = starting value; zeros = where the output is 0; maximum/minimum = largest/smallest output (say both the value and where); increasing/decreasing/constant intervals described by inputs.
5. **Average rate of change = (f(b) − f(a))/(b − a),** the slope of the segment between two points, with units. Constant for a line; interval-dependent for a curve; zero for a round trip.
6. **Domain = inputs that make sense; range = outputs produced.** Decided by the situation (whole numbers of tickets, time until the tank empties) or read from a graph (open dots exclude, filled dots include). Discrete domains give graphs of separate points.
7. **Piecewise and absolute value.** A piecewise function uses the piece whose inequality holds; watch the boundary. |x| is distance from 0: a V with vertex where the inside is zero; |x − a| + b has vertex (a, b); |x − a| ≤ c means a − c ≤ x ≤ a + c.
8. **An inverse undoes a function.** Solve for the input; domain and range swap; exists only if outputs never repeat. It is not a reciprocal.

## Key formulas and procedures

| Task | Procedure |
|---|---|
| Is it a function? | does each input have exactly one output? |
| Interpret f(a) = b | input a (with units) gives output b (with units) |
| Rule from a table | rate = change in output per unit input; constant = output at input 0 |
| Solve f(x) = k | set the rule equal to k and solve; or read where the graph meets height k |
| Average rate of change | (f(b) − f(a))/(b − a) |
| Domain from a situation | restrict to sensible inputs: non-negative, whole numbers, until the quantity runs out |
| Domain and range from a graph | x-values covered; y-values reached; respect open/filled dots |
| Evaluate a piecewise function | find the piece containing the input; boundary goes to the piece with ≤ or ≥ |
| Vertex of an absolute value graph y = abs(x − a) + b | (a, b); minimum b if the V opens up |
| Solve abs(x − a) = c | x = a + c or x = a − c |
| Inverse of y = mx + c | x = (y − c)/m |
| Build a linear model from two readings | rate = change ÷ time; start from the first reading; check against other data |

## Worked examples

**Notation.** B(t) = bicycles available t hours after 8 a.m. B(2) = 11: eleven bikes at 10 a.m. Solve B(t) = 11: every t with eleven bikes, perhaps t = 2 and t = 3.

**Rule.** Table 1 → 7, 2 → 10, 3 → 13: rate 3, value 4 at 0, g(x) = 3x + 4. g(x) = 31 at x = 9.

**Features.** Drone: starts at 0, peaks at 60 m at t = 4, hovers at 20 m for 7 ≤ t ≤ 10, lands at t = 12. Zeros t = 0, 12; maximum 60 at t = 4; constant on 7 < t < 10. Average rate 0 to 4: 15 m/min; 4 to 7: −40/3 ≈ −13.3 m/min; 0 to 12: 0.

**Compare.** A(m) = 50 + 20m; B(0) = 200, B(12) = 320 so B(m) = 200 + 10m. Equal at m = 15; A larger afterwards.

**Domain.** Tickets at $12, at most 8: domain whole numbers 0–8, range 0, 12, …, 96. Tank V = 500 − 20t: domain 0 ≤ t ≤ 25, range 0 to 500.

**Piecewise.** Parking $3 first hour, $2 each extra hour or part, cap $15: C(2.5) = 7; range 3, 5, 7, 9, 11, 13, 15; steps with open left dots and filled right dots.

**Absolute value.** E(L) = |L − 50|: V with vertex (50, 0). |L − 50| ≤ 1 gives 49 ≤ L ≤ 51. |x − 3| = 5 gives x = 8 or −2.

**Inverse.** C(t) = 15t + 20 → t = (d − 20)/15; $95 buys 5 hours. F = 1.8c + 32 → c = (F − 32)/1.8.

**Battery.** 100% at 8:00, 76% at 11:00: rate −8 per hour, B(t) = 100 − 8t; 20% at t = 10 (18:00); empty at 12.5 (20:30); if 14:00 reads 40% instead of 52%, the drain sped up and a piecewise model is better.

## Common errors

- Reading f(3) as f × 3; swapping input and output in f(a) = b.
- Evaluating when asked to solve, or stopping at one solution of f(x) = k.
- Reporting where a maximum occurs when asked for its value.
- Describing intervals by outputs instead of inputs.
- Forgetting to divide by the change in input in an average rate of change.
- Taking the domain from the formula instead of the situation; joining the dots of a discrete graph.
- Using the wrong piece at a boundary of a piecewise function.
- Putting the vertex of |x − 3| at x = −3; treating |x| as "drop the sign" inside expressions.
- Writing the inverse as a reciprocal; undoing operations in the wrong order.

## Quick drills (answers at the end)

1. W(d) is a puppy's weight after d days. Write "after 30 days it weighed 4 kg" in notation.
2. f(x) = 5x − 2. Find f(4); solve f(x) = 33.
3. A graph has f(0) = 4, zeros at 2 and 8, maximum 10 at x = 5. Where is f positive?
4. Average rate of change of g(x) = x² from 3 to 5?
5. Domain and range of M(n) = 40 − 2.5n, money left after n sandwiches from $40?
6. p(x) = 4 − x for x < 1, 2x + 1 for x ≥ 1. Find p(1) and p(−3).
7. Vertex and range of y = |x + 1| + 4?
8. Inverse of T(h) = 60h + 40? Hours for $250?

*Answers:* (1) W(30) = 4. (2) 18; x = 7. (3) 2 < x < 8. (4) (25 − 9)/2 = 8. (5) Whole numbers 0 to 16; 40, 37.5, …, 0. (6) 3; 7. (7) (−1, 4); y ≥ 4. (8) h = (d − 40)/60; 3.5 hours.
