## What you need to be able to do

- **4.1** Decide whether a relationship is a function (each input has exactly one output), and describe and sketch a graph of a situation in words.
- **4.2** Read and write function notation: f(x) is the output of f at input x; f(3) = 7 says the input 3 produces the output 7.
- **4.3** Interpret statements such as f(2) = 15 or f(a) = f(b) in context, and evaluate or solve from a graph or table.
- **4.4** Write a rule in function notation from a description, a table or a graph, and evaluate it.
- **4.5** Use a rule to find an output from an input and an input from an output, including with technology and with non-linear rules.

## Key terms

| Term | Meaning |
|---|---|
| Function | A rule that assigns exactly one output to each input. |
| Input (independent variable) | The quantity you choose or that comes first, on the horizontal axis. |
| Output (dependent variable) | The quantity determined by the input, on the vertical axis. |
| Function notation | f(x), read "f of x": the output of f when the input is x. Not multiplication. |
| f(a) = b | The input a gives the output b; on the graph, the point (a, b). |
| Rule | A formula, table or graph that tells how to get the output from the input. |
| Vertical line test | A graph is a function if no vertical line crosses it more than once. |

## Functions and situations (4.1)

A relationship is a **function** when knowing the input pins down the output. "The temperature at each time of day" is a function of time: at 3:00 there is one temperature. "The time at which the temperature is 20 °C" is not a function of temperature: 20 °C might occur at 9:00 and again at 19:00.

**Worked example.** A bath is filled for 8 minutes, left for 20 minutes, then drained in 4 minutes. Describe the graph of water depth against time.
Rises steadily for 8 minutes, stays level (horizontal) for 20 minutes, then falls steeply to zero over 4 minutes. Depth is a function of time: each moment has one depth.

**Worked example.** Is "a student's height" a function of "the student's age"? Is "the student" a function of "height"?
Height at a given age is one number, so yes. Many students share a height, so "the student" is not a function of height.

**Try it.** A ball is thrown upward and caught. Sketch in words the graph of height against time, and say whether height is a function of time.
*Answer:* Rises, slows, peaks, falls back; a smooth arch. Yes: each time has one height. (Time is not a function of height, since most heights occur twice.)

## Function notation (4.2, 4.3)

Write f(x) for the output of a function f at input x. If C gives the cost in dollars of x tickets, then C(4) = 50 means "four tickets cost $50". The input is in the parentheses; the output is the value of the expression.

Reading from a table of C: if the row x = 4 shows 50, then C(4) = 50. Reading from a graph: the point (4, 50) on the graph of C says C(4) = 50.

**Interpreting statements.**

- **T(6) = 21** where T(h) is temperature at hour h: at 6 o'clock the temperature was 21°.
- **T(6) = T(18)**: the temperature at 6 and at 18 was the same (the statement does not say what it was).
- **T(12) > T(6)**: it was warmer at noon than at 6.
- **Solve T(h) = 25**: find every hour when the temperature was 25°, which may be several inputs.

**Worked example.** P(t) is the number of people in a café t hours after opening. Write in notation: "two hours after opening there were 15 people"; "at 5 hours there were more people than at 2"; "when were there 30 people?"
P(2) = 15; P(5) > P(2); solve P(t) = 30.

**Worked example.** From a graph of d(t), distance from home in km after t minutes, the point (10, 3) is on the graph and the graph reaches 0 again at t = 40. Interpret.
d(10) = 3: after 10 minutes the walker is 3 km from home. d(40) = 0: at 40 minutes the walker is back home.

**Try it.** A(n) is the area of a square of side n. Write "a square of side 5 has area 25" and "which side gives area 81?" in notation, and answer the second.
*Answers:* A(5) = 25; solve A(n) = 81, giving n = 9.

## Writing rules (4.4, 4.5)

A rule turns the description into an expression.

- "A taxi charges $3 plus $2.50 per mile": f(m) = 2.5m + 3.
- "The perimeter of a square of side s": P(s) = 4s.
- "The number of dollars left from $200 after buying n books at $12": L(n) = 200 − 12n.
- From a table with inputs 1, 2, 3, 4 and outputs 7, 10, 13, 16: outputs rise by 3 each step and would be 4 at input 0, so g(x) = 3x + 4.

**Evaluating:** f(6) = 2.5(6) + 3 = 18. **Solving for the input:** f(m) = 28 means 2.5m + 3 = 28, so m = 10.

**Non-linear rules** work the same way. If A(s) = s² is the area of a square, A(7) = 49 and A(s) = 144 gives s = 12. If h(t) = 40t − 5t² is a ball's height in metres after t seconds, h(2) = 80 − 20 = 60, and h(t) = 0 at t = 0 and t = 8.

**Technology.** Entering a rule into a graphing tool lets you read any output and trace to find inputs that give a target output; a table feature lists outputs for a run of inputs.

**Worked example.** A phone plan costs $20 a month plus $0.10 per text. Write the rule, find the cost of 150 texts, and find how many texts give a $35 bill.
C(t) = 20 + 0.1t; C(150) = 35; C(t) = 35 gives 0.1t = 15, t = 150.

**Try it.** g(x) = 3x + 4. Find g(10) and solve g(x) = 31.
*Answers:* 34; 3x + 4 = 31, x = 9.

## Common mistakes

- Reading f(3) as "f times 3". It is the output at input 3.
- Confusing input and output in f(a) = b: a goes in, b comes out, and the point is (a, b), not (b, a).
- Saying a relationship is not a function because two inputs share an output (that is allowed) instead of checking whether one input has two outputs (not allowed).
- Evaluating when the question asks to solve: f(10) asks for an output; f(x) = 10 asks for the inputs.
- Dropping units when interpreting a statement in context.

## Self-check

1. Is "the price of a stamp" a function of "the year"? Is "the year" a function of "the price of a stamp"?
2. W(d) is the weight of a puppy after d days. Write "after 30 days the puppy weighed 4 kg" in notation.
3. f(x) = 5x − 2. Find f(4) and solve f(x) = 33.
4. A table gives inputs 2, 4, 6 and outputs 9, 13, 17. Write a rule.
5. On the graph of g the point (3, 0) is marked. What does it say in notation?

*Answers:* (1) Yes (one price per year); no (one price covers many years). (2) W(30) = 4. (3) f(4) = 18; 5x − 2 = 33 gives x = 7. (4) Rises 4 per 2 units, so 2 per unit; at x = 0, 5: g(x) = 2x + 5. (5) g(3) = 0.
