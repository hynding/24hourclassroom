## What you need to be able to do

- **2.5** Graph an equation in two variables by plotting solutions, read solutions off a graph, and explain why every point on the graph is a solution and every solution is a point on the graph.
- **2.6** Recognise equivalent equations (same solutions) and explain which moves produce them: adding or subtracting the same quantity on both sides, multiplying or dividing both sides by the same non-zero number, and using the distributive property.
- **2.7** Write a justification for each step of solving an equation, and spot a step that is not valid (dividing by zero, or applying an operation to one side only).
- **2.8** Rearrange an equation to isolate a chosen variable, and explain why solving for a variable is useful when that quantity must be found many times.

## Key terms

| Term | Meaning |
|---|---|
| Graph of an equation | The set of all points (x, y) whose coordinates are solutions. For a linear equation, a line. |
| Intercept | Where the graph crosses an axis: the x-intercept has y = 0, the y-intercept has x = 0. |
| Equivalent equations | Equations with exactly the same solutions. |
| Acceptable moves | Add/subtract the same thing on both sides; multiply/divide both sides by the same non-zero number; replace an expression by an equal one (distribute, combine like terms). |
| Distributive property | a(b + c) = ab + ac. |
| Solve for a variable | Rewrite the equation so the chosen variable is alone on one side. |
| Literal equation | An equation with several letters, such as P = 2l + 2w; "solving for w" produces w = (P − 2l)/2. |

## Graphs of two-variable equations (2.5)

Every solution of 2x + y = 8 is a pair, and a pair is a point. Some solutions: (0, 8), (1, 6), (2, 4), (4, 0), (−1, 10). Plot them and they line up; the line through them is the graph, and it contains every solution (including non-integer ones like (1.5, 5)) and nothing else.

Two points fix a line, and the intercepts are the easiest to find:

- **y-intercept**: set x = 0. 2(0) + y = 8, so y = 8. Point (0, 8).
- **x-intercept**: set y = 0. 2x = 8, so x = 4. Point (4, 0).

Draw the line through (0, 8) and (4, 0); check a third solution such as (2, 4) lies on it.

**Reading a graph.** If the graph of a cost equation passes through (10, 95), then 10 of the item cost $95: a point on the graph is a solution and tells you a pair of values that go together. A point off the line, such as (10, 80), is a pair that does **not** satisfy the equation.

**Worked example.** A snack stand's income from s sandwiches at $5 and d drinks at $2 was $60: 5s + 2d = 60. Graph it and interpret the intercepts.
Intercepts: s = 0 gives d = 30; d = 0 gives s = 12. The line through (0, 30) and (12, 0) (with s on the horizontal axis) shows every combination that makes $60. (0, 30) means 30 drinks and no sandwiches; (12, 0) means 12 sandwiches and no drinks; (8, 10) is on the line and means 8 sandwiches and 10 drinks. Points between the integer solutions have no meaning here, because you cannot sell half a sandwich.

**Try it.** Find the intercepts of 3x − 4y = 24 and one more solution.
*Answer:* (0, −6) and (8, 0); (4, −3) also works since 12 + 12 = 24.

## Equivalent equations (2.6)

Two equations are **equivalent** when they have exactly the same solutions. 3x + 2 = 11 and 3x = 9 and x = 3 are all equivalent: each is true only when x = 3. Solving an equation is a chain of equivalent equations ending with the variable alone.

What keeps equations equivalent:

1. **Add or subtract the same quantity on both sides.** 3x + 2 = 11 becomes 3x = 9 by subtracting 2 from both sides.
2. **Multiply or divide both sides by the same non-zero number.** 3x = 9 becomes x = 3 by dividing both sides by 3.
3. **Rewrite either side as an equal expression.** 2(x + 4) = 14 becomes 2x + 8 = 14 by distributing; 5x − 2x + 1 = 7 becomes 3x + 1 = 7 by combining like terms.

What breaks equivalence: doing something to one side only (3x + 2 = 11 → 3x = 11), multiplying both sides by zero (every equation becomes 0 = 0), or dividing by an expression that could be zero (dividing x² = 3x by x loses the solution x = 0).

**Worked example.** Are 4(y − 2) = 20 and y − 2 = 5 equivalent? Yes: divide both sides of the first by 4. Both have the single solution y = 7. Are 2x = 10 and 2x + x = 10 + x equivalent? Yes: the same quantity x was added to both sides. Are x + 3 = 8 and 2x + 3 = 16 equivalent? No: the first has solution 5, the second 6.5; the right side was doubled but only part of the left side was.

**Try it.** Which equation is equivalent to 6x − 4 = 20: (a) 6x = 16, (b) 3x − 2 = 10, (c) x − 4 = 20/6?
*Answer:* (b): both sides of the original divided by 2. (a) subtracted 4 from only one side; (c) divided only part of the left side.

## Justifying every step (2.7)

Write the reason beside each line. For 5(x − 3) + 2x = 3x + 13:

| Step | Reason |
|---|---|
| 5x − 15 + 2x = 3x + 13 | distributive property |
| 7x − 15 = 3x + 13 | combine like terms |
| 4x − 15 = 13 | subtract 3x from both sides |
| 4x = 28 | add 15 to both sides |
| x = 7 | divide both sides by 4 |

Check: 5(7 − 3) + 14 = 20 + 14 = 34; 3(7) + 13 = 34. ✓

A **step that is not valid** looks like a solving step but changes the solutions. Spotting them is a skill of its own: "from 2x + 6 = 10 we get x + 6 = 5" is wrong (only the 2x and the 10 were halved; the 6 was not). "From 4x = 4y we get x = y" is fine (divide both sides by 4), but "from xy = xz we get y = z" is not, because x might be zero.

**Try it.** Find the invalid step: 3x + 9 = 21 → 3x = 12 → x = 4 → x + 2 = 8.
*Answer:* The last step: adding 2 to the left and 4 to the right. x = 4 and x + 2 = 8 have different solutions.

## Solving for a variable (2.8)

Sometimes you need one quantity from an equation over and over. A party planner using 40 + 11p = C wants to answer "how many pizzas for $C?" for many budgets. Solving for p once, **p = (C − 40)/11**, turns every later question into a substitution: for $150, p = 110/11 = 10; for $205, p = 15.

The moves are the same as solving a numeric equation; the letters just stay letters.

**Worked example.** Solve P = 2l + 2w for w.
Subtract 2l from both sides: P − 2l = 2w. Divide both sides by 2: **w = (P − 2l)/2**. For P = 30 and l = 9, w = (30 − 18)/2 = 6.

**Worked example.** Solve 3x + 5y = 30 for y.
Subtract 3x: 5y = 30 − 3x. Divide by 5: **y = (30 − 3x)/5** = 6 − (3/5)x. For x = 5, y = 3.

**Try it.** Solve d = rt for t, and find t when d = 300 and r = 60.
*Answer:* t = d/r; t = 5.

## Common mistakes

- Plotting a point off the line and still calling it a solution; a solution must satisfy the equation exactly.
- Mixing up which intercept has which coordinate equal to zero.
- Operating on one side only, or on one term of a side instead of the whole side.
- Dividing both sides by a variable that might be zero.
- When solving for a variable, dividing only part of the other side: from 5y = 30 − 3x writing y = 30 − 3x/5.
- Forgetting to check the solution in the original equation.

## Self-check

1. Find the intercepts of 5x + 2y = 20.
2. Is (2, 5) on the graph of 5x + 2y = 20?
3. Which is equivalent to 2(x + 3) = 14: x + 3 = 7 or 2x + 3 = 14?
4. Solve A = (1/2)bh for h.
5. Find the invalid step: 4x − 8 = 12 → 4x = 20 → x = 5 → 2x = 20.

*Answers:* (1) (0, 10) and (4, 0). (2) 10 + 10 = 20, yes. (3) x + 3 = 7 (both sides divided by 2); 2x + 3 = 14 distributed incorrectly. (4) h = 2A/b. (5) The last step: 2x should be 10, not 20.
