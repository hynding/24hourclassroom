## The ideas that generate every question

1. **An unknown input is an equation.** "When is the ball 36 feet up?" means solve h(t) = 36. Areas, frames, projectiles and revenue all produce ax² + bx + c = 0 once a value is fixed.
2. **A square has two roots.** If (something)² = k > 0, then something = √k or −√k. Isolate the square first: 3x² − 5 = 70 becomes x² = 25, x = ±5; (x − 1)² = 16 gives x = 5 or −3.
3. **Zero product property.** ab = 0 forces a = 0 or b = 0, and nothing else does. Get 0 on one side, factor, split: x² + 3x = 40 becomes (x + 8)(x − 5) = 0.
4. **Factoring is product-and-sum.** x² + bx + c = (x + m)(x + n) with mn = c and m + n = b; signs follow c and b. Special cases: a² − b² = (a − b)(a + b), x² + 2kx + k² = (x + k)². With a ≠ 1, try factor pairs of a and c. Not everything factors.
5. **Completing the square always works.** Add (b/2)² to both sides: x² + 6x − 7 = 0 becomes (x + 3)² = 16. Divide by a first if a ≠ 1. Non-square right sides give irrational solutions: (x − 2)² = 7, x = 2 ± √7.
6. **The quadratic formula is completing the square in general.** x = (−b ± √(b² − 4ac))/(2a) for ax² + bx + c = 0. Four slips: dividing by 2 instead of 2a; the sign of −b; b² when b < 0; −4ac when c < 0.
7. **The discriminant predicts.** b² − 4ac negative: no solutions; zero: one; positive perfect square: two rational; positive non-square: two irrational.
8. **Rational and irrational.** Rational + rational and rational × rational are rational; rational + irrational and non-zero rational × irrational are irrational; irrational with irrational can be either (√2 · √8 = 4).
9. **Vertex form by completing the square.** Factor a out of the x² and x terms (never divide a function), add and subtract (b/2)², multiply the subtracted part by a. The vertex gives the maximum or minimum.
10. **Modelling.** Starting value from c; landing or break-even from the zeros; peak from the vertex; where two graphs meet from f(x) = g(x).

## Key formulas and procedures

| Task | Procedure |
|---|---|
| Square isolated | (x − h)² = k: x = h ± √k; no solution if k < 0; one if k = 0 |
| Zero product | Rearrange to 0, factor, set each factor to 0, check |
| Factor x² + bx + c | numbers with product c, sum b; both negative if c > 0 and b < 0; one of each if c < 0 |
| Difference of squares | a² − b² = (a − b)(a + b) |
| Perfect square | x² + 2kx + k² = (x + k)²; test: (b/2)² = c |
| Factor ax² + bx + c | (px + m)(qx + n) with pq = a, mn = c, pn + mq = b |
| Complete the square (equation) | move c; add (b/2)² to both sides; square; roots |
| Leading coefficient (equation) | divide every term by a first |
| Quadratic formula | x = (−b ± √(b² − 4ac))/(2a), from ax² + bx + c = 0 |
| Discriminant | b² − 4ac: < 0 none, = 0 one, perfect square rational, otherwise irrational |
| Vertex form (function) | a(x² + (b/a)x) + c → a(x + b/(2a))² + c − a(b/(2a))² |
| Max or min | k at x = h; max if a < 0, min if a > 0 |
| Line meets parabola | set expressions equal, solve, find the y-values |
| Check | substitute into the original equation; decimals give "close to 0" |

## Worked examples

**Reasoning.** (x + 3)² = 100: x = 7 or −13. x² = −9: none. (x − 4)² = 0: x = 4 only.

**Zero product.** (x − 3)(x + 7) = 0: 3, −7. 64t − 16t² = 0: 16t(4 − t) = 0, t = 0 or 4. (x − 3)(x + 7) = 10 cannot be split.

**Factoring.** x² + 9x + 20 = (x + 4)(x + 5); x² − 3x − 28 = (x − 7)(x + 4); x² − 11x + 24 = (x − 3)(x − 8); x² − 49 = (x − 7)(x + 7); x² + 12x + 36 = (x + 6)²; 2x² + 7x + 3 = (2x + 1)(x + 3); 3x² − 10x − 8 = (3x + 2)(x − 4).

**Solving by factoring.** x² = 5x + 24: (x − 8)(x + 3) = 0, x = 8 or −3. Frame: (12 + 2x)(16 + 2x) = 320 gives x² + 14x − 32 = 0, (x + 16)(x − 2) = 0, x = 2 inches.

**Completing the square.** x² + 3x − 10 = 0: (x + 3/2)² = 49/4, x = 2 or −5. 2x² + 12x + 10 = 0: x² + 6x + 5 = 0, (x + 3)² = 4, x = −1 or −5. x² − 4x − 3 = 0: (x − 2)² = 7, x = 2 ± √7 ≈ 4.65, −0.65. Pool: w² + 4w − 50 = 0, (w + 2)² = 54, w = −2 + √54 ≈ 5.35.

**Formula.** 2x² − 5x − 3 = 0: discriminant 49, x = (5 ± 7)/4 = 3 or −1/2. x² + 6x + 4 = 0: (−6 ± √20)/2 ≈ −0.76, −5.24. x² = 3x + 5: rearrange, (3 ± √29)/2. −16t² + 40t + 6 = 0: discriminant 1,984, t ≈ 2.64 s.

**Discriminant.** 3x² + 2x + 5: −56, none. x² + 4x + 4: 0, one. x² − 2x − 3: 16, rational. x² − 2x − 4: 20, irrational. 4x² + bx + 9: one solution when b = ±12.

**Vertex form.** x² − 6x + 2 = (x − 3)² − 7. 2x² + 8x + 1 = 2(x + 2)² − 7. −x² + 4x + 1 = −(x − 2)² + 5. R(p) = −4p² + 80p = −4(p − 10)² + 400: best price 10. h(t) = −16t² + 64t + 20 = −16(t − 2)² + 84: peak 84 at t = 2; lands at (16 + √336)/8 ≈ 4.29.

**Intersections.** y = x + 1 and y = x² − 2x − 3: x² − 3x − 4 = 0, points (4, 5) and (−1, 0). Ball −16t² + 48t + 5 and drone 5 + 8t: level at t = 0 and t = 2.5.

## Common errors

- Giving only the positive root of a square.
- Setting factors equal to a non-zero number.
- Dividing by x and losing x = 0.
- Wrong middle sign when factoring; calling x² + 25 a difference of squares; x² − 49 as (x − 7)².
- Adding (b/2)² to one side only; using b/2 instead of (b/2)².
- Dividing only some terms by a; dividing a function by a.
- Formula: denominator 2, sign of −b, negative b², −4ac with negative c, splitting the root.
- Reading a, b, c before the equation equals 0.
- "Irrational + irrational is irrational."
- Reporting the input when the output was asked, or a time before the launch.

## Quick drills (answers at the end)

1. Solve (x + 5)² = 49.
2. Solve x(x − 8) = 0 and (2x − 3)(x + 4) = 0.
3. Factor x² − 7x + 12, x² + 2x − 48, x² − 121, 2x² − 5x − 3.
4. Solve x² + 4x = 21 by factoring.
5. Solve x² − 10x + 18 = 0 by completing the square.
6. Solve 3x² − 2x − 4 = 0 with the formula, to two decimal places.
7. Describe the solutions of x² − 6x + 9 = 0 and x² − 6x + 10 = 0 from the discriminant.
8. Write −2x² + 12x − 11 in vertex form and state its maximum.
9. Where do y = 3x − 2 and y = x² meet?
10. Is √18 · √2 rational?

*Answers:* (1) x = 2 or −12. (2) 0, 8; 3/2, −4. (3) (x − 3)(x − 4); (x + 8)(x − 6); (x − 11)(x + 11); (2x + 1)(x − 3). (4) (x + 7)(x − 3) = 0: −7, 3. (5) (x − 5)² = 7: 5 ± √7. (6) discriminant 4 + 48 = 52; x = (2 ± √52)/6 ≈ 1.54 or −0.87. (7) 0: one solution, 3; −4: none. (8) −2(x − 3)² + 7; maximum 7. (9) x² − 3x + 2 = 0: (1, 1) and (2, 4). (10) Yes: √36 = 6.

## What to review from earlier units
