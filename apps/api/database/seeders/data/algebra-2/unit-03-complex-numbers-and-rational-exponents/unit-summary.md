## The ideas that generate every question

1. **New exponents are defined so the old rules keep working.** a⁰ = 1 because aⁿ/aⁿ must be 1; a⁻ⁿ = 1/aⁿ because a⁰/aⁿ must equal it; a^(1/n) = ⁿ√a because (a^(1/n))ⁿ must equal a¹. Everything in week 11 follows from the product rule aᵐ · aⁿ = aᵐ⁺ⁿ and the power rule (aᵐ)ⁿ = aᵐⁿ.
2. **A rational exponent is a root and a power.** a^(m/n) = (ⁿ√a)ᵐ: the denominator is the root index, the numerator is the power. Take the root first to keep numbers small. A negative exponent means reciprocal, never a negative answer.
3. **√a is one number; x² = a has two solutions.** The radical symbol names the nonnegative root. Cube roots are different: every real number has exactly one, including negatives.
4. **Squaring is not reversible; cubing is.** a = b implies a² = b², but a² = b² also allows a = −b. So squaring both sides can create extraneous solutions and every candidate must be checked in the original equation. Cubing keeps the sign and adds nothing.
5. **The radical-equation routine:** isolate the radical, raise both sides to the matching power, solve, check. An isolated square root equal to a negative number means no solution.
6. **i is defined by i² = −1, and all the arithmetic rules are kept.** Powers of i cycle every four. √(−a) = i√a. A complex number a + bi is a point (a, b) in the complex plane.
7. **Complex arithmetic is binomial arithmetic plus i² = −1.** Add and subtract by parts; multiply by distributing; multiply by i to rotate a quarter turn; divide by multiplying top and bottom by the conjugate of the denominator.
8. **The conjugate a − bi makes products real:** (a + bi)(a − bi) = a² + b². Non-real solutions of a real-coefficient quadratic always come as a conjugate pair.
9. **Completing the square and the quadratic formula now never fail.** A negative right side, or a negative discriminant, gives ±i·(something). The discriminant b² − 4ac predicts two real, one real or two non-real solutions, and the number of x-intercepts.

## Key formulas and procedures

| Want | Do this |
|---|---|
| aᵐ · aⁿ, aᵐ/aⁿ, (aᵐ)ⁿ | aᵐ⁺ⁿ, aᵐ⁻ⁿ, aᵐⁿ |
| a⁰, a⁻ⁿ | 1, 1/aⁿ |
| a^(1/n) | ⁿ√a (for even n, the nonnegative root) |
| a^(m/n) | (ⁿ√a)ᵐ; e.g. 27^(4/3) = 3⁴ = 81, 16^(3/4) = 2³ = 8 |
| a^(−m/n) | 1/a^(m/n); e.g. 8^(−2/3) = 1/4; (1/9)^(−1/2) = 3 |
| Radical to exponent | ⁿ√(aᵐ) = a^(m/n); √(x⁵) = x^(5/2) |
| Solve (x − h)² = k, k > 0 | x = h ± √k |
| Solve √(expr) = other | isolate, square, solve, check each candidate |
| Solve ∛(expr) = c | cube both sides; no check needed for extraneous solutions |
| Powers of i | i, −1, −i, 1 repeating; use the remainder of the exponent on division by 4 |
| √(−a), a > 0 | i√a; √(−12) = 2i√3 |
| Add / subtract | combine real parts and imaginary parts |
| Multiply | distribute, replace i² with −1, collect |
| Divide | multiply top and bottom by the conjugate of the bottom |
| Conjugate product | (a + bi)(a − bi) = a² + b² |
| Square roots of p + qi | solve a² − b² = p and 2ab = q for real a, b; answers ±(a + bi) |
| Complete the square | leading coefficient 1; add (b/2)² to both sides; undo with ± |
| Quadratic formula | x = (−b ± √(b² − 4ac)) / (2a); divide every term by 2a |
| Discriminant | b² − 4ac: > 0 two real, = 0 one real, < 0 two non-real (conjugates) |
| Quadratic from solutions r and s | x² − (r + s)x + rs = 0; for 3 ± i: x² − 6x + 10 = 0 |

## Common errors

- Reading 4^(−1/2) as −2. It is 1/2.
- Writing √49 = ±7. The symbol gives 7; the equation x² = 49 gives ±7.
- Squaring before isolating: (√x + 2)² is x + 4√x + 4, not x + 4.
- Skipping the check after squaring, or rejecting a negative candidate without checking it (x = −4 does solve √(x² + 9) = 5).
- Leaving i² in an answer or treating it as +1. (2 + 3i)(2 − 3i) = 13, not −5.
- Taking the imaginary part of 7 − 3i to be −3i. It is −3.
- Combining √(−4) · √(−9) into √36 = 6. Convert first: (2i)(3i) = −6.
- Dividing only the real term in (4 ± 2i√3)/2. Both terms are halved: 2 ± i√3.
- Reading a negative discriminant as "no solutions". There are two; they are non-real.
- Forgetting the second square root of a complex number: if 3 + i works, so does −3 − i.

## Worked examples

**Evaluate 32^(−3/5).** ⁵√32 = 2, so 32^(3/5) = 8 and 32^(−3/5) = 1/8.

**Solve √(x + 10) = x − 2.** Square: x + 10 = x² − 4x + 4, so x² − 5x − 6 = (x − 6)(x + 1) = 0. Check 6: √16 = 4 and 6 − 2 = 4 ✓. Check −1: √9 = 3 but −1 − 2 = −3 ✗. Solution {6}.

**Solve ∛(4x + 1) = −3.** Cube: 4x + 1 = −27, so x = −7. Cubing is reversible, so −7 is the solution with no check needed (though ∛(−27) = −3 confirms it).

**Simplify (3 + i)(1 − 2i).** 3 − 6i + i − 2i² = 3 − 5i + 2 = 5 − 5i.

**Write (2 + 6i)/(1 + i) as a + bi.** Multiply by (1 − i)/(1 − i): (2 − 2i + 6i − 6i²)/2 = (8 + 4i)/2 = 4 + 2i. Check: (1 + i)(4 + 2i) = 4 + 2i + 4i + 2i² = 2 + 6i ✓.

**Find the square roots of −9 − 40i.** a² − b² = −9 and 2ab = −40, so ab = −20. Try (4, −5): 16 − 25 = −9 ✓. Roots 4 − 5i and −4 + 5i.

**Solve x² + 2x + 17 = 0.** (x + 1)² = −16, so x = −1 ± 4i. Check x = −1 + 4i: x² = 1 − 8i + 16i² = −15 − 8i; 2x = −2 + 8i; −15 − 8i − 2 + 8i + 17 = 0 ✓.

**Solve 2x² − 2x + 1 = 0.** Discriminant 4 − 8 = −4. x = (2 ± 2i)/4 = 1/2 ± (1/2)i.

**Classify without solving.** x² + 3x − 1: 9 + 4 = 13, two real. x² − 4x + 4: 0, one real. 2x² + x + 1: 1 − 8 = −7, two non-real. The last graph never touches the x-axis.

## What to review from earlier units

- **Unit 1:** geometric sequences use the exponent rules (the nth term a · rⁿ⁻¹); fractional inputs such as 2^(1/12) now make sense.
- **Unit 2:** factoring quadratics finishes most radical equations; the remainder theorem and factored forms appear as review items; rational equations were the first place extraneous solutions appeared, for the same reason (multiplying by something that can be zero is not reversible).

## Exam-night checklist

1. Can you evaluate 27^(4/3), 16^(−3/4) and (1/8)^(−1/3) without a calculator? (81, 1/8, 2.)
2. Can you explain why √36 is 6 but x² = 36 has two solutions?
3. Can you solve a radical equation and say which candidate is extraneous and why?
4. Can you say why cube-root equations never need an extraneous check?
5. Can you simplify i⁵⁷, √(−45), (2 − 3i)², and (5 + 5i)/(1 + 2i)? (i, 3i√5, −5 − 12i, 3 − i.)
6. Can you find both square roots of 8 + 6i?
7. Can you solve x² − 6x + 13 = 0 two ways and check a solution? (3 ± 2i.)
8. Can you classify a quadratic's solutions from its discriminant and sketch what its graph does at the x-axis?
9. Can you build a quadratic with integer coefficients from a conjugate pair of solutions?
