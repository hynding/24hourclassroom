## The ideas that generate every question

1. **Perception is sensation plus interpretation (2.1).** Bottom-up processing builds from features; top-down processing uses schemas, perceptual set, context, culture and emotion. Selective attention lets us focus but causes inattentional blindness and change blindness. Gestalt principles (figure-ground, proximity, similarity, closure) group the scene; binocular cues (retinal disparity, convergence) and monocular cues (relative size, interposition, relative clarity, texture gradient, linear perspective) give depth; constancies keep size, shape and color stable; apparent movement makes stills move.
2. **Thinking runs on shortcuts (2.2).** Concepts and prototypes sort the world; schemas grow by assimilation and change by accommodation. Executive functions live largely in the prefrontal cortex. Algorithms guarantee answers; heuristics (availability, representativeness) are fast but biased. Obstacles: mental set, functional fixedness, confirmation bias, belief perseverance, overconfidence, priming, framing, the gambler's fallacy and the sunk-cost fallacy. Creativity needs divergent thinking, then convergent thinking.
3. **Memory is several systems (2.3).** Explicit (episodic, semantic) versus implicit (procedural, priming, conditioning); prospective memory. The multi-store model (sensory, short-term, long-term), the working memory model (central executive, phonological loop, visuospatial sketchpad, episodic buffer) and levels of processing (structural, phonemic, semantic) each describe part of it. The hippocampus forms new explicit memories; the cerebellum and basal ganglia handle implicit ones; the amygdala strengthens emotional ones; the frontal lobes run working memory.
4. **What you do while learning decides what you keep (2.4).** Automatic processing captures space, time and frequency; everything else takes effort. Meaning, self-reference and imagery beat repetition; elaborative rehearsal beats maintenance rehearsal. Mnemonics (chunking, method of loci, acronyms, hierarchies) organize. Spaced practice beats cramming. The serial position effect favors first (primacy) and last (recency) items.
5. **Storage is a physical change (2.5).** Consolidation, helped by sleep and the hippocampus, stabilizes memories; long-term potentiation strengthens synapses. Anterograde amnesia blocks new memories; retrograde amnesia erases old ones. Infantile amnesia is normal. Alzheimer's disease destroys neurons, starting with memory areas.
6. **Retrieval depends on cues (2.6).** Recognition is easier than recall; relearning reveals hidden memory. Encoding specificity: context-dependent, state-dependent and mood-congruent memory. Retrieval practice (the testing effect) is the strongest study tool; metacognition tells you what you really know.
7. **Forgetting and distortion are normal (2.7).** The forgetting curve drops fast, then levels. Forgetting comes from encoding failure, decay or retrieval failure (tip of the tongue, proactive and retroactive interference). Memory is reconstructive: the misinformation effect, source amnesia, imagination inflation and false memories mean confidence is not accuracy. Repression is contested.
8. **Intelligence is measured, debated and shaped by environment (2.8).** g versus multiple intelligences; fluid versus crystallized. Binet's mental age, Terman's ratio IQ, Wechsler's deviation scores; the eugenics misuse. Tests must be standardized, reliable and valid. Heritability, the Flynn effect, stereotype threat, cultural bias and mindset all bear on scores.

## Key facts and numbers

| Fact | Value or rule |
|---|---|
| Iconic memory | under 1 second |
| Echoic memory | a few seconds |
| Short-term memory | about 20–30 seconds unrehearsed; about 7 ± 2 items (newer estimates about 4 chunks) |
| Ratio IQ | mental age ÷ chronological age × 100 |
| Intelligence score distribution | mean 100, SD 15 |
| Within 1 / 2 / 3 SD | about 68% / 95% / 99.7% |
| Score 115 / 130 | about 84th / 98th percentile |
| Good test reliability | correlation near +0.9 |
| Intellectual disability | score about 70 or below **and** adaptive limits, beginning in development |

## Confusable pairs

| Pair | How to tell them apart |
|---|---|
| Bottom-up / top-down | Features first / knowledge and expectation first |
| Inattentional / change blindness | Unexpected object never noticed / change between views not noticed |
| Binocular / monocular cues | Only retinal disparity and convergence need two eyes |
| Availability / representativeness | Ease of recall / resemblance to a prototype |
| Mental set / functional fixedness | Stuck on a strategy / stuck on an object's usual use |
| Assimilation / accommodation | Fit into the old schema / change the schema |
| Episodic / semantic | Personal event with time and place / general fact |
| Maintenance / elaborative rehearsal | Repetition / linking to meaning |
| Primacy / recency | First items (long-term memory) / last items (short-term memory) |
| Anterograde / retrograde amnesia | No new memories / lost old memories |
| Context- / state-dependent memory | External setting / internal condition |
| Proactive / retroactive interference | Old harms new / new harms old |
| Fluid / crystallized intelligence | New reasoning / stored knowledge |
| Aptitude / achievement test | Predicts the future / measures past learning |
| Reliability / validity | Consistent / accurate |

## Classic studies to describe (in your own words)

- **Simons and Chabris (1999):** viewers counting passes often missed a person in a gorilla suit (inattentional blindness).
- **Gibson and Walk (1960):** crawling infants avoided the visual cliff (early depth perception).
- **Tversky and Kahneman (1970s):** availability, representativeness and framing.
- **Luchins's water jars and Duncker's candle problem:** mental set and functional fixedness.
- **Atkinson and Shiffrin (1968); Baddeley and Hitch (1974); Craik and Lockhart (1972):** the multi-store, working memory and levels-of-processing models.
- **Henry Molaison:** no new explicit memories after hippocampal removal, yet improving procedural skill.
- **Ebbinghaus (1880s):** the forgetting curve and the spacing effect.
- **Godden and Baddeley (1975):** divers' context-dependent recall.
- **Loftus and Palmer (1974):** "smashed" versus "hit" changed speed estimates and memories of broken glass.
- **Spearman, Gardner, Binet, Terman, Flynn, Steele and Aronson, Dweck:** g, multiple intelligences, mental age, the IQ ratio, rising scores, stereotype threat, mindset.

## Research methods in this unit

- **Perceptual set and framing studies** are between-subjects experiments: random assignment to a prime or a wording, with the reported interpretation or choice as the DV.
- **Levels-of-processing studies** are often within-subjects: counterbalance the order of conditions.
- **Context-dependent memory** needs a crossed design (learn and test in both settings) so that one setting simply being worse is ruled out.
- **Misinformation studies** need a neutral control group as a baseline, and deception requires IRB review and debriefing.
- **Test validation** uses correlations: test-retest and split-half for reliability, correlation with an outcome for predictive validity. Correlation still does not show cause.
- **Statistics:** a statistically significant result is unlikely to be due to chance alone; effect size tells you how big the difference is. A difference of several standard deviations means groups barely overlap.

## Free-response reminders

- **AAQ (7 points):** name the method (experiment only with manipulation and random assignment); state the operational definition as a measurement ("number of words recalled out of 20"); describe what the statistic shows in context; name a specific ethical guideline; tie generalizability to the actual sample; use a named concept to explain whether the findings support the claim.
- **EBQ (7 points):** a claim that answers the prompt; cite each source by letter with a specific result; explain each with a *different* named concept from this unit.
