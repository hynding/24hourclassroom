## Key terms

| Term | Meaning |
|---|---|
| Memory | Learning that persists over time: information that has been encoded, stored and can be retrieved. |
| Explicit (declarative) memory | Facts and experiences you can consciously recall and state. |
| Episodic memory | Explicit memory of personal events tied to a time and place. |
| Semantic memory | Explicit memory of general facts and knowledge. |
| Implicit (nondeclarative) memory | Memory shown in behavior without conscious recollection: skills, conditioned responses, priming. |
| Procedural memory | Implicit memory for how to perform skills. |
| Prospective memory | Remembering to do something in the future. |
| Sensory memory | A very brief, large-capacity record of sensory input. |
| Short-term memory | A limited-capacity store holding information for seconds without rehearsal. |
| Working memory | Short-term memory seen as an active workspace for manipulating information. |
| Long-term memory | The relatively permanent, very large store of knowledge and skills. |
| Long-term potentiation | A lasting increase in a synapse's efficiency after repeated stimulation. |

## Kinds of memory

Psychologists split long-term memory into two families.

**Explicit memory** (also called declarative memory) is what you can consciously bring to mind and describe. It has two forms:

- **Episodic memory**: your own experiences, with a when and a where. "My tenth birthday party at the bowling alley."
- **Semantic memory**: general knowledge, detached from when you learned it. "A bowling lane is about 60 feet long."

**Implicit memory** (nondeclarative memory) shows up in behavior without conscious recall:

- **Procedural memory**: how to ride a bike, type, or tie a shoelace. You can do it far better than you can explain it.
- **Priming**: earlier exposure makes a related response easier, without awareness (week 8 used priming in judgment).
- **Classically conditioned responses**: feeling tense at the dentist's drill sound (Unit 3 develops this).

**Prospective memory** is remembering to do something later: taking medicine at 8 p.m., or handing in a permission slip on Friday. It depends on cues and on executive functions in the frontal lobes.

**Worked example 1: classifying memories.** (a) Knowing that Paris is the capital of France: semantic (explicit). (b) Remembering the day you got your learner's permit: episodic (explicit). (c) Shifting gears smoothly without thinking: procedural (implicit). (d) Remembering to text your mom when practice ends: prospective.

## The multi-store model

The **information-processing** approach compares memory to a computer: information is **encoded** (put in), **stored** (kept) and **retrieved** (taken out). The best-known version, the multi-store model proposed by Richard Atkinson and Richard Shiffrin in 1968, has three stores:

1. **Sensory memory** holds a brief, nearly complete snapshot of what the senses register: under a second for vision (**iconic memory**) and a few seconds for sound (**echoic memory**). Most of it fades before we notice it.
2. **Short-term memory** receives what we **attend to**. It holds a small amount, classically described as about seven items, plus or minus two (George Miller's 1956 estimate; later research suggests nearer four chunks), for about 20 to 30 seconds unless it is rehearsed. **Maintenance rehearsal**, repeating the information, keeps it active.
3. **Long-term memory** holds information that has been encoded more deeply. Its capacity is essentially unlimited. Information moves back into short-term memory when it is retrieved.

The model explains why you forget a phone number you just heard if someone interrupts you (it never left short-term memory) and why attention matters so much (unattended sensory information never enters short-term memory).

## Working memory

In 1974 Alan Baddeley and Graham Hitch argued that short-term memory is not a passive waiting room but an active workspace: **working memory**. In their model, later expanded by Baddeley:

- the **central executive** directs attention and coordinates the other parts;
- the **phonological loop** holds and rehearses sounds and words (your inner voice repeating a number);
- the **visuospatial sketchpad** holds images and spatial layouts (picturing the route to a friend's house);
- the **episodic buffer** (added in 2000) links information from the other parts and from long-term memory into a single episode.

Because the loop and the sketchpad are separate, two tasks that use different parts interfere less than two tasks that use the same part. Listening to a podcast while drawing a map is easier than listening to a podcast while reading.

## Levels of processing

Fergus Craik and Robert Lockhart proposed in 1972 that memory depends less on *which store* information is in than on **how deeply it is processed**:

- **Structural (shallow)**: noticing what a word looks like ("Is it in capital letters?").
- **Phonemic (intermediate)**: noticing how it sounds ("Does it rhyme with *weight*?").
- **Semantic (deep)**: thinking about its meaning ("Is it a kind of fruit?").

Deeper processing produces better memory. This is why explaining an idea in your own words beats rereading it.

## Memory in the brain

Different kinds of memory depend on different structures:

| Structure | Role in memory |
|---|---|
| Hippocampus | Forms new explicit memories and helps consolidate them for long-term storage. |
| Frontal lobes | Working memory, and retrieving and organizing explicit memories. |
| Cerebellum | Implicit memories for timed motor responses and classically conditioned reflexes. |
| Basal ganglia | Procedural memories for skills and habits. |
| Amygdala | Strengthens memories of emotional events. |

The case of **Henry Molaison** (known in research as H.M.) made this division famous. In 1953, surgeons removed much of both his medial temporal lobes, including most of the hippocampus, to treat severe epilepsy. Afterward he could not form new explicit memories: he could not remember people he met daily. Yet when he practiced tracing a star while looking only at its mirror image, his skill improved across days even though he did not remember practicing. His implicit, procedural memory still worked.

At the level of neurons, memory depends on **long-term potentiation (LTP)**: repeated stimulation of a synapse makes the receiving neuron more responsive, so the connection strengthens. This links memory to week 3's synapse and neurotransmitters, and week 11 returns to it.

## Research methods spotlight: testing levels of processing

**Worked example 2: a within-subjects experiment.** In a hypothetical study, 30 students each saw 60 words, one at a time. For 20 words they answered a structural question (Is it in capital letters?), for 20 a phonemic question (Does it rhyme with *chair*?), and for 20 a semantic question (Is it a kind of animal?). The order of question types was counterbalanced. Later, with no warning, they were asked to recall as many words as they could.

| Question type | Mean words recalled (of 20) | Standard deviation |
|---|---|---|
| Structural | 3.2 | 1.4 |
| Phonemic | 6.1 | 1.9 |
| Semantic | 11.4 | 2.3 |

- *IV:* the level of processing (structural, phonemic, semantic). *DV:* the number of words recalled.
- *Design:* within-subjects (repeated measures): every participant experienced every condition, so individual differences in memory ability cannot explain the differences between conditions.
- *Counterbalancing:* varying the order of conditions keeps fatigue or practice from favoring one level.
- *Interpretation:* recall more than tripled from shallow to deep processing, as the levels-of-processing model predicts. The larger SD in the semantic condition shows more spread in how much participants recalled there.

**Worked example 3: a case study's limits.** H.M. is a **case study**: a detailed look at one person. It revealed that explicit and implicit memory depend on different structures, a finding later confirmed in other patients and in animal research. But one case cannot show how typical the pattern is, and his epilepsy and medications may have played a role, which is why case studies generate hypotheses that larger studies then test.

## Common mistakes

- **Swapping episodic and semantic.** Episodic has a personal time and place; semantic is a fact you could look up.
- **Calling procedural memory explicit.** If you can do it without being able to say how, it is implicit.
- **Treating short-term and working memory as unrelated.** Working memory is a model of how short-term memory actively processes information.
- **Saying the hippocampus stores all memories.** It is vital for forming new explicit memories; long-term memories are stored across the cortex, and implicit memories rely on the cerebellum and basal ganglia.

## Self-check

1. Remembering your first day of high school is which kind of memory?
2. Why can you still type quickly though you could not name the keys on the bottom row?
3. Which store holds an image for a fraction of a second after a camera flash?
4. Which component of working memory is used when you mentally rotate a puzzle piece?
5. Which processing level is "Does *table* rhyme with *cable*?"
6. Why could H.M. improve at mirror tracing without remembering the practice?

*Answers:* 1. Episodic (explicit). 2. Typing is procedural (implicit) memory. 3. Iconic sensory memory. 4. Visuospatial sketchpad. 5. Phonemic (intermediate). 6. Procedural memory depends on the cerebellum and basal ganglia, which his surgery spared.
