# Week 27 · Numerical Patterns and Their Graphs

**Standard:** 5.OA.B.3 Make two numerical patterns from rules and graph their ordered pairs
**Built from:** IM K–5 Math Grade 5, Unit 7, Section C, in our own words

## What you will learn

- Make a number pattern from a rule like "start at 0, add 4".
- Put two patterns in a table and match up their **terms**.
- Turn matching terms into **ordered pairs** and graph them.
- Describe how two patterns are related, like "each term of B is 3 times the term of A".

## Words to know

| Word | What it means |
|---|---|
| Pattern | A list of numbers made by following a rule. |
| Rule | Where the pattern starts and what to do each time. |
| Term | Each number in a pattern. |
| Matching terms | Terms in the same position in two patterns. |
| Relationship | How a term of one pattern compares with the matching term of the other. |

## Making a pattern from a rule

A rule has two parts: a starting number and a step. "Start at 0, add 4" gives 0, 4, 8, 12, 16, 20, ... Each number is a **term**. The 1st term is 0, the 2nd is 4, and so on.

**Try it.** Write the first five terms of "start at 0, add 9". 0, 9, 18, 27, 36.

## Two patterns side by side

Now make two patterns with two rules and line them up in a table, one pattern in each row.

| Term number | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| Pattern A: start at 0, add 2 | 0 | 2 | 4 | 6 | 8 |
| Pattern B: start at 0, add 10 | 0 | 10 | 20 | 30 | 40 |

Each column holds a pair of **matching terms**. Look down the columns: 2 and 10, 4 and 20, 6 and 30. Each Pattern B term is **5 times** the Pattern A term.

Why does that happen? Both patterns start at 0 and take the same number of steps. Pattern B adds 10 each step, which is 5 times the 2 that Pattern A adds. After any number of steps, B has added 5 times as much, so it is 5 times as big.

**Watch out.** The difference between matching terms is not the same each time: 0, 8, 16, 24, 32. So "B is 8 more than A" is wrong. When both patterns start at 0, look for "times as much".

## From a table to a graph

To graph two patterns, make an **ordered pair** from each column. Use the Pattern A term as the x-coordinate and the matching Pattern B term as the y-coordinate.

From the table above: (0, 0), (2, 10), (4, 20), (6, 30), (8, 40). Plot them on a coordinate grid, and they line up in a straight row that starts at the origin and climbs steadily.

**Try it.** Pattern A: start at 0, add 1. Pattern B: start at 0, add 4. Ordered pairs: (0, 0), (1, 4), (2, 8), (3, 12). What would the next point be? Add 1 to x and 4 to y: (4, 16).

The steeper the row of points, the faster Pattern B grows compared with Pattern A. Points for "B is 4 times A" climb more steeply than points for "B is 2 times A".

## Two patterns over time

Sometimes both patterns are graphed against the same x-values, like days. Nadia saves 3 dollars a day and her brother Kenji saves 6 dollars a day, both starting with 0. Plot each one's total for days 0 to 5 on the same grid with different markers. Kenji's points climb twice as steeply, and on every day his total is 2 times Nadia's: 6 and 3 on day 1, 12 and 6 on day 2, and so on.

## For grown-ups at home

Make patterns with everyday things: "You read 2 pages a minute, I read 6 pages a minute. How many pages after 1, 2, 3, 4 minutes?" Write the two lists side by side and ask how the numbers compare. Then plot the pairs on graph paper. Ask: "If we kept going, what would the next point be? Why does mine stay 3 times yours?"

## Check yourself

1. Write the first four terms of "start at 0, add 6".
2. Pattern A: 0, 5, 10, 15. Pattern B: 0, 15, 30, 45. How does each B term compare with the matching A term?
3. Using the patterns in question 2, write the ordered pair from the 3rd terms.
4. A graph shows (0, 0), (1, 2), (2, 4), (3, 6). What is the next point if both patterns continue?
5. True or false: if A adds 3 and B adds 9, both from 0, each B term is 6 more than the A term.

*Answers:* (1) 0, 6, 12, 18. (2) Each B term is 3 times the A term. (3) (10, 30). (4) (4, 8). (5) False: each B term is 3 times the A term, and the gap grows.
